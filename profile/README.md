# ShopNex

  **Open-source ecommerce you own.** Self-host your store or run it in the cloud, with no platform lock-in.

  -  **Complete storefront and admin.** Products, orders, customers, discounts and shipping, all configured in the admin UI.
  -  **Liquid themes.** Familiar LiquidJS templates for the storefront.
  -  **Payments through apps.** Stripe ships as a bundled app, and core never touches card data.
  -  **Extensions that stay out of your core.** Apps run out-of-process and authenticate with signed keys, so they can't break your store.
  -  **Growth built in.** SEO, transactional email, and file storage on local disk or any S3-compatible bucket.
